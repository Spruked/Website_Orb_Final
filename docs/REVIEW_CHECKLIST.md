# Review Checklist

- `compiled_orb/site_world.json` exists and validates.
- Route context endpoint is lookup-only.
- Pointer map is loaded once and indexed.
- Runtime language is loaded once.
- Frontend component avoids cursor hovering and moves freely.
- Pointer action resolves DOM targets before visual guidance.
- DockStation integration is adapter-only.
- No live crawl, scan, or page-capsule assembly exists in the runtime path.
